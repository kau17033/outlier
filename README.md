# 関証 KANSHO｜検証基盤

「顧客に示せる、検証可能な物差しを。」

関証は、仕入れと採算の判定を費用の6項目すべてで行い、その結果を取引先や金融機関に提出できる署名つき文書として発行する検証基盤です。EC支援事業者・卸・物流など、自社の顧客に対して根拠を示して説明しなければならない組織向けに、検証文書の発行・継続監査・クライアント提示用の証明を提供します。

- 判定に入れる6項目: 販売価格／原価／送料／販売手数料／返品に備える分／その他の変動費
- 判定: 候補／保留／却下 の3区分
- 発行記録は署名つきで、改ざんを検出できます（検証者に依存しない検証）
- 価格（検証中の設定）: 導入パイロット ¥30,000（固定）／継続監査は月額相談

ご相談: ページ内のフォームから受け付けています。

※ 関証が保証するのは記録の同一性であり、将来の利益ではありません。売上の保証、仕入れや販売の代行は行いません。
